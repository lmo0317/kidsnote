# Google Stitch 모바일 화면 자료

실제 아이 사진과 계정정보를 제외한 Stitch 업로드용 화면입니다.

1. `01-mobile-empty.png` — 로그인 전·사진 조회 전 기본 화면
2. `02-mobile-login.png` — 키즈노트 계정 연결 바텀시트
3. `03-mobile-loading.png` — 사진 조회 로딩 화면
4. `04-mobile-results.png` — 가짜 이미지로 구성한 조회 결과 화면

## 권장 사용 순서

- Stitch 새 프로젝트에서 `01-mobile-empty.png`를 기준 이미지로 먼저 업로드합니다.
- 나머지 3장은 같은 프로젝트의 추가 화면/상태 참고 이미지로 넣습니다.
- 생성 지시에는 모바일 세로 전용, 전체 화면 폭, 한 열 사진 목록, 큰 한글 글꼴을 유지한다고 명시합니다.
- 실제 아이 사진이 포함된 캡처는 업로드하지 않습니다.
