신청서를 작성하면 관리자가 확인한 뒤 사진과 알림장을 모아 이메일로 보내드립니다. 아래 순서대로 진행해 주세요.

사진 전달 신청하기 →
  1. 01신청서 작성
  2. 02관리자 확인
  3. 03이메일 다운로드

STEP 01

신청 정보를 입력해 주세요

키즈노트 로그인 정보와 자료를 받을 이메일을 정확하게 입력합니다.

  • 키즈노트 ID·비밀번호사진 수집을 위해 사용하며, 승인 또는 거절 후 로그인 정보는 삭제됩니다.
  • 받는 이메일완료 안내와 다운로드 링크를 받을 주소입니다.
  • 사진 연도특정 연도 또는 전체 기간을 선택할 수 있습니다.
  • 포함 자료알림장 텍스트를 체크하면 날짜별 UTF-8 텍스트 파일로 함께 저장합니다.
  • 폴더 구성년 / 월 / 일 또는 년 / 월 중 원하는 방식을 선택합니다.
  • 전달 내용구매처 아이디나 주문자명처럼 신청 확인에 필요한 내용을 적습니다.
TIP 일별 폴더를 선택하면 같은 날짜의 사진과 알림장.txt가 한 폴더에 들어갑니다.

STEP 02

관리자 확인 후 수집이 시작됩니다

접수된 신청을 관리자가 확인하고 수락하면 선택한 기간의 사진과 알림장 수집을 시작합니다.

1신청 접수입력한 정보를 확인합니다.
→
2관리자 수락수집 작업을 시작합니다.
→
3이메일 발송ZIP이 준비되면 알려드립니다.

사진 수에 따라 작업 시간이 달라질 수 있습니다. 작업이 끝날 때까지 신청을 반복하지 않아도 됩니다.

STEP 03

이메일에서 ZIP을 내려받으세요

완료 메일에는 다운로드 버튼, 파일 삭제 버튼, 압축 비밀번호가 함께 표시됩니다.

  • 다운로드버튼을 눌러 사진과 알림장이 담긴 ZIP 파일을 저장합니다.
  • 압축 비밀번호메일에 표시된 비밀번호로 ZIP 파일을 엽니다. AES-256을 지원하는 7-Zip 또는 WinZip을 권장합니다.
  • 파일 삭제더 이상 공유 파일이 필요하지 않으면 확인 화면을 거쳐 즉시 삭제할 수 있습니다.
  • 7일 유효다운로드 링크는 발송 후 7일이 지나면 자동으로 만료됩니다.
주의 파일 삭제를 완료하면 같은 링크로 다시 받을 수 없습니다. 먼저 ZIP 다운로드와 압축 해제를 확인해 주세요.
